# 전기차 충전소 접근성 연구 — 프로젝트 요약 (2026-07-20 기준)

## 연구 개요
지리학과 도시컴퓨팅 연구실 소속 연구. 서울 동대문구 경희대학교 인근 충전소 파악에서
시작해, 서울시 25개 자치구 전체, 이후 서울+6대 광역시(부산·대구·인천·광주·대전·울산)
전체로 범위를 확장하며 전기차 충전소 접근성(가용률, 위치, 완속/고속 비율)을 분석 중.

- 저장소: https://github.com/dralex0122/ev (branch: main)
- API: 한국환경공단 전기차 충전소 정보 API (공공데이터포털, B552584)
- 서비스키는 전부 환경변수(`EV_SERVICE_KEY`, 지오코딩은 `VWORLD_API_KEY`)로 관리, 코드에 하드코딩하지 않음

## 데이터 수집 스크립트 계보
1. `collect_seoul_hourly.py` — 서울 25개 구, 시간대별 가용률 자동 수집(현재 비활성화, 24시간 수집 완료)
2. `metro7_ev_chargers.py` / `metropolitan_ev_stations.py` — 서울+6대 광역시 충전소 위치·완속/고속
   대수 GeoJSON 생성. 초기 버전은 페이지 실패 시 해당 도시 전체를 포기하는 버그가 있었고,
   사용자가 제공한 버전은 실패한 페이지만 건너뛰는 더 견고한 로직이었음 — 이후 두 스크립트 모두
   같은 방식으로 통일
3. `district_availability_snapshot.py` — 서울+6대 광역시를 **구/군 단위**로 쪼개 가용률(전체
   대수/가용 대수/비율, 완속·고속 구분) 계산. 주소 파싱으로 구/군을 추출하며, 이상치(파싱 실패,
   알려진 구/군 목록에 없는 이름)를 자동 탐지해 `anomalies_<시>.json`으로 별도 기록

## 발견한 데이터 품질 이슈
- **원본 API의 좌표 오류**: 일부 충전소가 라벨된 시/도와 동떨어진 좌표(예: 서울 충전소인데
  좌표는 제주 인근)를 가짐 — 두 개의 독립적인 스크립트에서 동일하게 재현되어 소스 데이터
  자체의 문제로 확인. VWorld 지오코딩 API로 주소 기반 재계산해 803건 중 766건 해결(37건은
  VWorld도 주소를 못 찾아 원값 유지 + `geocoding_suspect` 플래그)
- **원본 API의 주소 오류**: 대전 충전소인데 주소 필드가 경기도 파주시/강원도 원주시로
  잘못 등록된 사례 확인 (파싱 문제 아님, 소스 데이터 자체 오기재)
- **중복 등록 의심**: 이름+주소+충전기 대수까지 완전히 같은 레코드가 242그룹(초과 레코드
  266개, 충전기 약 1,108대) — 서로 다른 사업자가 같은 물리 충전기를 각자 등록했을 가능성
- **테스트/더미 레코드**: "테스트용", "TEST" 등 이름이 들어간 실제 존재하지 않는 레코드
  14건을 원본에서 확인 후 제외
