# 전기차 충전소 접근성 연구 — 프로젝트 요약 (2026-08-23 기준)

## 연구 개요
지리학과 도시컴퓨팅 연구실 소속 연구. 서울 동대문구 경희대학교 인근 충전소 파악에서
시작해 서울시 25개 자치구, 서울+6대 광역시(부산·대구·인천·광주·대전·울산), 경기도까지
수집 범위를 넓혔고, 현재는 **서울 단일 지역 2021-2024년 장기(longitudinal) 접근성 변화**로
연구 스코프를 좁혀 G2SFCA(2단계 부양권역법) 기반 통행시간 접근성 분석을 진행 중.
**최종 방법론은 2026-08-19~21에 확정**(아래 "최종 확정 방법론" 절 참고), 현재는 지도·형평성
지표 산출을 마치고 방법론 문서화·발표 준비 단계.

- 저장소: https://github.com/dralex0122/ev (branch: main)
- API: 한국환경공단 전기차 충전소 정보 API (공공데이터포털, B552584)
  - 2026-08-02~08-03 http(80포트) 장애로 20시간+ 수집 중단 발생, 이후 **https(443포트)로 고정** —

## 접근성 분석 파이프라인
- G2SFCA: t0=15분 임계치(threshold-cutoff) 방식, `nx.single_source_dijkstra_path_length`로
  충전소별 통행시간 계산, `scipy.spatial.cKDTree`로 좌표→그래프 노드 매칭
- 수요(D1): 집계구(2016년 경계) 단위 생활인구, 연도(2021-2024)×시간대(오전/낮/밤/심야) 평균
- 공급(S)은 4가지 정의로 전체 80개 조합(4개년×2요일유형×[오전/낮/밤 3시나리오 + 심야 1시나리오])을
  모두 실행해 강건성(robustness) 비교 완료 — `g2sfca_run.py --supply {s1,s2,s2park,sfast}`:
  - **S1**: 충전소 단순 대수(무가중) — `output/g2sfca/`
  - **S2**: 급속:완속 = 2.4:1, 프로젝트 자체 10분 가용률 루프 실측(세션 빈도 기반) —
    `output/g2sfca_s2/`
  - **s2park**: 급속:완속 = 10:1, Park et al.(2022, 강남·서초·송파) 문헌값 — 강건성 비교용,
    `output/g2sfca_s2_park10/`
  - **sfast(2026-08-15 추가)**: 완속충전기를 아예 배제, 급속충전기 보유 충전소만 공급으로
    인정 — 지도교수 제안(가중치 논쟁 대신 완속을 제외). `yearly_snapshots_fastonly/`(연도별
    급속 1대 이상 보유 충전소만 필터링) 사용, `output/g2sfca_sfast/`
- **강건성 비교 결과(2026-08-11, S1/S2/s2park)**: 2021→2024 접근성 개선 추세는 가중치 방식과
  무관하게 강건함(S1 4.78배, S2 4.67배, s2park 4.35배 증가). 집계구 단위 상관관계는 S1↔S2
  Pearson 0.996, S1↔s2park 0.937 — S2가 S1과 공간 패턴이 더 유사하고, s2park는 급속충전기
  밀집지역 점수를 상대적으로 더 부풀리는 경향 확인. Notion 2026-08-10 토글에 상세 기록
- **sfast 비교 결과(2026-08-15)**: 2021→2024 증가율 3.88배로 S1/S2보다 낮음(서울 급속 보유
  비율이 2021년 24.9%→2024년 18.3%로 오히려 감소한 것과 일치). 공간 패턴 상관관계는
  S1↔sfast 0.746, S2↔sfast 0.799로 지금까지 비교한 것 중 가장 낮음. **0(접근불가) 집계구가
  처음 발생**(S1/S2/s2park는 0%였는데 sfast는 2021년 평균 3.08%→2024년 0.91%) — 완속 배제
  시 일부 지역은 15분 내 급속충전소가 아예 없어짐, 형평성(equity) 관점의 핵심 논의 지점
- 거리조락함수(distance decay)도 `--decay {binary,gaussian}`으로 파라미터화(2026-08-13) —
  binary(t0=15분 이내 가중치 1)는 그동안 검토 없이 쓰던 단순화, gaussian(Luo&Qi 2009
  E2SFCA 공식)은 교수님 논문(Park et al. 2022) 원 코드가 실제로 쓰는 방식. S2 기준 두 방식
  다 2021→2024 증가율 4.67배로 동일(강건함)하지만, 공간 패턴 상관관계는 0.885로 공급가중치
  비교(0.996)보다 뚜렷이 낮음 — decay 함수 모양이 "어디가 접근성 좋은가"의 공간 분포 자체에
  더 큰 영향을 줌. **2026-08-15부터 `--decay` 기본값을 gaussian으로 변경**(사용자 지시,
  binary는 이제 명시적으로 지정해야 함). Notion 2026-08-13 토글에 상세 기록

위 "접근성 분석 파이프라인" 절의 강건성 비교(공급 4종·거리조락 2종)를 거쳐 최종적으로 아래처럼
확정. 이하 4가지는 지도교수 논의 없이 사용자가 직접 확정한 결정사항.

- **① 공급(S)**: `sfast`(급속충전기만 인정) + **아파트 소재 충전소 완전 제외**. "유료주차장
  급속충전기는 예외로 포함"하는 절충안은 폐기하고 블랭킷 제외로 단순화
  - 아파트 판정은 v1(키워드 매칭, 31.2%)→v3(키워드+브랜드명+역지오코딩+note필드+건축물대장
    50m 공간조인+한국부동산원 공동주택단지 마스터리스트, **57.3%**, 서울 급속+완속 9,830건 중
    5,634건)로 3단계 정밀화. `output/apt_charger_flags/seoul_chargers_2024_apt_v3_final.csv`
  - v3는 **2024년 충전소 목록으로만 분류**돼 2021-2023년엔 근사(station_id로 연도별 매칭) —
    2026-08-21 검증: 2021-2023년 서울 급속충전소 전수(687/959/1,449개)가 2024년 목록에
    100% 존재(누락 0건)해 실측 오차 없음 확인. 충전소 개수·위치·운영시간 자체는 각 연도 고유
    자료를 그대로 사용(2024로 대체된 적 없음), 2024 기준 표는 아파트 여부 라벨 조회에만 사용
- **② 분석 시간대**: 오전(7\~9시, 출근시간)·낮(11\~13시)·**심야(00\~05시, 2026-08-21
  02\~03시에서 확장)** 3구간. 밤(17\~18시)은 최종 방법론에서 제외
  - 심야 확장 근거: 선행논문 Park et al.(서울 EV, 우리 핵심 벤치마크)과 NYC 헬스케어 접근성
    논문이 독립적으로 nighttime을 "00:00\~06:00"으로 정의 — 취침시간대라는 개념과도 부합
  - 다른 시간대(오전/낮)는 특정 통행 레짐을 대표하는 좁은 2시간 스냅샷인 반면, 심야는 벤치마크
    논문이 "접근성이 낮고 균일화(low and equalized)"된다고 서술하는 동질적 구간이라 6시간으로
    넓게 잡아도 무방(오히려 표본 안정성에 유리) — 기준이 다른 게 아니라 각 구간의 실제
    동질성 범위에 맞춘 것
  - 생활인구 집계(`building_register/aggregate_oa_population_periods.py`)도 심야를
    00\~05시(6개 시간) 기준으로 재집계, `d1_final_2021_2024.csv` 갱신(기존 02\~03시 파일은
    `_bak_2hr_simya` 접미사로 보존)
  - 평일/주말 구분은 오전·낮에는 적용하지만 **심야는 불필요**로 확정 — 실측 비교 결과 평일/주말
    차이가 모든 연도·거리조락함수 조합에서 0.3% 미만(사실상 오차 수준)
- **③ 운영시간 실측 반영**: 각 충전소의 `openinghour` 텍스트를 분석 시간창(오전 7\~9시/낮
  11\~13시/심야 00\~06시)·요일유형과 대조해 실제 운영 여부를 0/1로 반영(이전에 검토했던
  "24시간 대비 운영 비율(%)" 할인 방식은 시간대별로 따로 계산하는 구조와 맞지 않아 폐기)
  - 필터링 규모가 시간대별로 크게 다름: **낮은 1% 미만**(사실상 무시 가능)인 반면, **오전은
    15\~25%, 심야는 18\~27%**가 개점 전/폐점 후로 제외됨(연도가 지날수록 완화 추세) — 지도·
    해석 시 시간대별로 구분해서 언급 필요
- **④ 거리조락함수**: gaussian(E2SFCA, Luo&Qi 2009)과 exponential(β=1/300) **둘 다 각각
  따로 산출**(대표 하나를 고르지 않음) — 상관관계 0.942로 결과가 크게 갈리지 않음. 임계시간
  t0=15분(900초)은 기존과 동일 유지
- 구현: `g2sfca_final_supply.py`(오전/낮 4개 조합×4개년×2개 거리조락함수),
  `g2sfca_simya_supply.py`(심야, 평일 데이터만 사용). 둘 다 기존 `g2sfca_sfast_gaussian/`의
  캐시된 OD(이동시간)를 재사용해 Dijkstra 재계산 없이 처리
- **핵심 결과**: 2021→2024 접근성 3.7\~4.9배 증가(조합별), 심야는 4.8배(gaussian). 서울
  19,153개 집계구 전부 증가, 악화된 곳 0개 — "소외된 곳"은 정확히는 "덜 늘어난 곳"(강남권
  중심 증가율 최하위, 외곽 지역이 급속충전기 신규설치로 수렴)
- **지도 산출물**: 그리드 4장(`output/maps/g2sfca_final_{gaussian,exponential}_16maps.png`,
  `g2sfca_simya_{gaussian,exponential}_4maps.png`, 연도×시나리오 한눈에 비교용, 세트별 공유
  색상 스케일) + 개별 40장(`output/maps/individual/`, 발표 슬라이드용, 그리드와 동일 색상
  스케일 유지). 오전/낮 그리드와 심야 그리드는 색상 스케일이 서로 다른 기준이라 절대값 직접
  비교 금지
- **형평성 지표(Gini·Palma)**: `gini_palma.py`, 인구가중 방식. 5개 조합(오전/낮 4개+심야)
  ×gaussian/exponential 각각 따로 산출(선행논문 3편에서 조건별 지표를 각각 표로 비교하는 게
  표준 관례임을 확인, 하나로 합치지 않음). 결과는 `output/gini_palma_2021_2024.csv`
  - Gini는 조합별로 추세가 갈림(일관된 방향 없음): 심야는 0.142→0.124로 꾸준히 감소(평등해짐),
    weekend_오전(freeflow)은 0.119→0.155로 꾸준히 증가(불평등해짐), 나머지는 등락만 있고
    뚜렷한 추세 없음
  - 심야(Gini 0.12\~0.14)가 낮 시간대(0.23\~0.30)보다 뚜렷이 낮음 — 살아남은 충전소들
    사이에서는 오히려 고르게 분포. Palma도 같은 패턴으로 뒷받침
  - **주의**: Gini가 낮게 나온 조합(weekend_오전_freeflow, 심야)이 공교롭게 둘 다 freeflow
    교통 시나리오 — "교통정체 없으면 접근성이 공간적으로 평준화된다"는 해석과 "freeflow OD
    자체의 구조적 특성" 가능성을 아직 구분 못함, 발표 시 확정 결론처럼 말하지 않을 것
- **선행논문과의 차별점**: 심야를 "본다"는 것 자체는 Park et al.도 이미 함 — 차별점은
  아파트 제외·운영시간 실측 반영·4년 종단비교라는 **분석 방식 자체**. 네트워크 분석(이동시간)
  방법론은 오히려 한계로 인정할 부분(Park et al.은 상용 API 실측, 우리는 OSMnx+가정된
  교통 시나리오)
